## Priority 1 — Factual concerns (claims-auditor) — all FIXED in generator

1. **"verified present-state" / "REPL-verified data model" overstated.** The EDN header (lines 7–13) records that JVM-heap + EDN-file entities are test-guarded but the six MongoDB entities are snapshot-derived and **not** test-guarded (issue [#66](https://github.com/nubank/clojuredocs/issues/66)). The diagram presented all entities as uniformly "verified."
   - **Fix:** Sources bullet now reads "the data model (verification scope noted in its header)"; the legend paragraph now states the JVM-heap/EDN-file vs. MongoDB test-guard split and links #66.
2. **"ClojureDocs denormalizes these … not join keys" — false absolute.** `EXAMPLE_HISTORY.example_id` is an ObjectId join key, contradicting "not join keys."
   - **Fix:** `FK` row now says some references are embedded sub-documents and others are ObjectId join keys (with the `example_id` example).
3. **"denormalized copies" / "they copy" — provenance inferred, not in the EDN.** The EDN models `:embedded-var`/`:embedded-user` as inline sub-schemas but records no copy/sync semantics.
   - **Fix:** prose now says the sub-schemas are "stored inline on the parent document … whose fields they embed" (no copy/sync claim).
